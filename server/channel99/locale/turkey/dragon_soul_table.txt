# Ejder ruh tasi Vnum aciklamasi
# ITEM VNUM 100000'ler basamagindan FEDCBA olarak adlandirilirsa
# FE : ejder ruh tasi turu.	D : Seviye
# C : Aşama			B : Geliştirme
# A : Yedek numaralar...
# Bu sistemin disinda kalan ejder ruh tasi affedilmeyecektir.
# ok?
# Ejder ruh tasi cok fazla oldugundan Vnum daginik olursa,
#	Special item group ile gruplayarak islemek de zor -_-,
#	VnumHelper.h ile islemek de zor. -_-
# 	Sadece grup yakalamak icin binlerce satir yazmak gerekebilir...
# Vnum'a bir sistem oturtulup basamak tabanli olmalidir.

# Table, "Grup" ve "isim" ile baslar.
# Table icinde baska bir Table olabilir.
# Ama rastgele bir tablo yazarsaniz sunucu onu tanimaz.
# Gerekli tablolar asagidaki gibidir.
# BaseVnums, BaseAttrs, AddtionalAttrs, AttrSettings, UpgradeTable, ImproveTable,
# RefineTable, UpgradeMoneys, ImproveTable, RefineMoneys, WeightTable, DurationTable,
# DragonHeartExtTable, DragonSoulExtTable

# Olasilik tablosunun degerleri varsayilan olarak float turundedir.

# Önemli !!!!!
# Tabloyu incelerken #--# yazan kisimlar var, kesinlikle silmeyin.
#

# Bu vnum -> isim eslemesi.
# Bununla belirli vnum'lu ejder ruh tasinin turu (ismi) bulunur,
# O ejder ruh tasina ait ozelligi bulur.
# Ayrica burada yazili olmayan bir ejder ruh tasi asagidaki Grup taniminda varsa
