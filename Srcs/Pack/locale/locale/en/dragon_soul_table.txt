# dragon soul stone tables...										
# separated by TAB, open in Excel.										
# if viewing with vim, adjust tab width. (set ts=16 recommended)										
# parts in double quotes are not split. 										
# things like \" are not supported.										
										
# comment about dragon soul stone Vnum										
# if ITEM VNUM digits from the 100000s place are called FEDCBA										
# FE : dragon soul stone type.	D : Grade									
# C : Step			B : Refine							
# A : spare numbers... 										
# dragon soul stones outside this scheme will not be forgiven.										
# ok?										
# since there are so many dragon soul stones, if Vnums are scattered,										
#	hard to handle by grouping with special item group too -_-,									
#	hard to handle in VnumHelper.h as well. -_-									
# 	it may take thousands of lines just to define groups...									
# Vnum must follow a digit-based scheme.										
										
# a Table starts with "Group" and a "name".										
# a Table may contain another Table.										
# the server will not recognize a random table.										
# required tables are as follows.										
# BaseVnums, BaseAttrs, AddtionalAttrs, AttrSettings, UpgradeTable, ImproveTable,										
# RefineTable, UpgradeMoneys, ImproveTable, RefineMoneys, WeightTable, DurationTable,										
# DragonHeartExtTable, DragonSoulExtTable										
										
# probability table values are float by default.										
										
# IMPORTANT !!!!!										
# there are #--# markers in the table; never delete them.										
# 										
										
# this is the vnum to name mapping.										
# after finding which kind of dragon soul stone (its name) a specific vnum is,										
# find the attribute matching that dragon soul stone.										
# also, if a dragon soul stone not listed here is in the Group definitions below,										
# error.
