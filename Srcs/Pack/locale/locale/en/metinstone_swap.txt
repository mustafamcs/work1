# Group metinstone_swap description
# event_flag_value		: metin stone appearance change event flag value
# range_number			: metin stone vnum range number to change (the range number of the metinstone_swap_range group above)
# swap_vnum				: appearance change mob vnum
# can_use_mob_color		: whether to allow mob_proto mob color on appearance change (false: deny, true: allow)
# : while the metin stone appearance event flag is set, a vnum in range gets swap_vnum appearance.
